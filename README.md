# 🎁 Gift E-Commerce Web Application  

## 📖 Project Description (For Viva 🎤)
This project is a full-stack Gift E-Commerce Web Application developed to provide users with an interactive platform to browse, search, and purchase gift items online.

The system demonstrates core concepts of frontend development, backend API handling, database integration, and client-server architecture.

---

## 🎯 Objective
- Build a complete E-Commerce workflow  
- Understand full-stack development  
- Implement REST API communication  
- Manage user interaction and data handling  

---

## ✨ Key Features
- Product listing with categories  
- Search functionality  
- Add to cart  
- Payment simulation  
- User authentication  
- Backend APIs  

---

## 🏗️ System Architecture
User → Frontend → Backend → Database

---

## 🧠 Technologies Used
Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express.js  
Database: MongoDB  

---

## ⚙️ Installation & Setup
git clone <your-repo-link>  
cd project  
npm install  

Create .env file:
PORT=5000  
MONGO_URI=your_mongodb_connection_string  

Run:
node server.js  

---

## 🚀 Deployment
Push to GitHub and deploy using Render (backend) and Vercel/Netlify (frontend).
